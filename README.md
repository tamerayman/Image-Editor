# 🖼️ Image Editor

A lightweight web-based image editor built with HTML, CSS, and JavaScript. The application allows users to upload images, apply visual filters in real time, preview changes instantly, reset edits, and download the final image.

---

## ✨ Features

- Upload images from the local device
- Apply real-time image filters
- Adjust brightness
- Adjust contrast
- Adjust saturation
- Apply grayscale effect
- Apply sepia effect
- Apply blur effect
- Rotate image colors (Hue Rotate)
- Reset all changes
- Download the edited image

---

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🚀 Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
3. Upload an image.
4. Edit the image using the available controls.
5. Download the final result.
